Castletool

Bring Castle to its full potential

Castletool is a tool used for importing many things into the Castle app, such as full color images, videos, music, audio, and more.

Open Web App Install

Installation

Android app

Download and install the app from GitHub.

Install the Android App

Run the web app locally

git clone https://github.com/MGoosePlayZ/castletool-web
cd castletool-web/docs
python -m http.server 8000

Then open localhost:8000 in your browser.

Install the CLI

pip install castletool
castletool

Needs Python and pip.

Frequently asked questions

Is Castletool a virus?

No. Castletool is not, and never will be malicious. The source code is public on GitHub, so you can read it yourself.

Is Castletool free?

Yes. Every version is free to use.

Which version should I use?

The web version is the recommended platform for cross-platform compatibility, and the Android app is recommended for users that want a seamless experience. The CLI is no longer recommended due to it being inaccessible to most, and being updated less frequently.

Can you import fonts?

Well, kinda. Fonts are imported as a set of images, and not a native text blueprint, which is sad.

Can you make an iOS app?

No, I cannot. It would be too expensive and too much of a hassle to get it on the App Store, and sideloading would be too annoying for most users.

Where do I report a bug or ask for a feature?

Open an issue on the project's GitHub page.
